## 🔭 What I've Been Working On

### 🛡️ LLM Security Evaluation Platform — *Secure IVAI (Aug–Dec 2025)*
Led an Agile team of 6 to build an internal platform that evaluated **10 HuggingFace LLMs across 10 OWASP vulnerability categories**.
- Python backend services automating vulnerability detection and compliance checks, cutting manual analysis time by ~50%
- 3 PostgreSQL schemas plus data pipelines for user profiles, test results, and audit logs, consolidated into one queryable reporting layer
- Git branching workflows and CI/CD pipelines across the team, with zero broken deployments over the project lifecycle

### ☸️ Personal Kubernetes Homelab
3-node bare-metal **K3s** cluster on repurposed enterprise hardware.
- Node affinity pins storage-dependent services to a dedicated node, decoupling storage from compute
- Self-hosted DNS filtering, media server, photo management, and file storage via Deployments, Services, and PVCs
- systemd-managed recovery on reboot and power loss

### 📈 Stock Price Predictor
Supervised ML regression pipeline (scikit-learn) predicting closing prices 30 days out, with cross-validation across models, real-time ingestion via the Quandl API, and Matplotlib performance dashboards.

### ✈️ Flight Planning System
C++ weighted directed graph modeling flight networks, computing optimal routes by cost and time using iterative backtracking with pruning. Built with OOP principles, separating graph traversal from I/O.
